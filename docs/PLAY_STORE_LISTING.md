# Oddly Fun: Mini Games

## Short description

Three silly 20-second games for instant tapping, spotting and sorting fun.

## Full description

Need a tiny brain break? Oddly Fun gives you three quick games that start
instantly and finish in about twenty seconds.

- Pop Rush: burst every colorful bubble before time runs out.
- Odd One: spot the sneaky emoji hiding in the crowd.
- Color Drop: sort each bright drop into the matching bin.

Build a daily streak, chase personal bests and collect coins while every run
gets a little faster. No account, no complicated tutorial and no internet
needed for the core games.

Made for one-thumb play during quick breaks.
